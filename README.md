# codergirl.megha — portfolio

Cinematic portfolio for **Megha Mittal**, frontend developer at Wiley.

**Live:** https://meghamittal0920.github.io/coder-girl/

- Scroll-scrubbed straw-hat intro (canvas frame sequence)
- Horizontal-scroll project gallery with tilt cards, featuring madaramusic.com
- Parallax, particles, scroll reveals — built with React, GSAP ScrollTrigger, Lenis and [React Bits](https://reactbits.dev) components

## Run locally

```bash
npm install
npm run dev
```

Pushing to `main` builds the site and publishes `dist/` to the `gh-pages` branch.
